이제 AI에게 물어보면, Lupa가 찾아냅니다

Lupa는 커맨드라인(CLI)을 내장합니다. Claude·Hermes·OpenClaw 같은 AI 에이전트와 Obsidian 같은 도구가 여러분의 자연어를 Lupa 검색어로 바꿔, 수십만 개 파일을 0.1초 안팎에 뒤집니다. 물론 전부 이 Mac 안에서만.

나"심사보고서에서 경영검토 관련 파일 찾아줘"
AIlupa-search "f:심사보고서 c:경영검토"
→ 601건 매치 · 0.11초 · 하이라이트 스니펫 포함 (JSON)

에이전트에게 그냥 find로 시키면 느리고 파일명만 훑습니다. Lupa CLI는 미리 인덱싱된 DB를 씁니다.

01시작하기

3단계면 끝

Lupa는 사용자가 선택한 폴더만 읽습니다 (macOS 샌드박스). 검색할 위치만 등록하면 됩니다.

1단계

App Store에서 설치하고 실행

처음 실행하면 폴더 선택 화면이 뜹니다. ‘홈 폴더 전체 검색’을 누르면 문서·다운로드·바탕화면이 한 번에 등록됩니다.

2단계

iCloud·외장 디스크는 ‘빠른 추가’로

홈 폴더 검색은 iCloud Drive와 외장 디스크를 포함하지 않습니다. 설정(⌘,) → 폴더 → 빠른 추가에서 버튼 한 번으로 등록하세요.

iCloud Drive 다운로드 바탕화면 문서 외장 디스크

보안상 각 위치를 처음 추가할 때 시스템이 “허용”을 한 번 물어봅니다. 빠른 추가 버튼이 그 위치로 바로 이동된 창을 열어줘서 클릭 한 번이면 됩니다.

3단계

인덱싱은 처음 한 번뿐입니다

백그라운드에서 파일을 미리 읽어둡니다. ⌥Space를 누르고 기억나는 조각을 입력하세요 — 아래 레시피처럼.

앱을 업데이트해도 인덱스는 그대로 유지됩니다. 새 버전을 받았다고 처음부터 다시 훑는 일은 없습니다. 등록한 폴더와 설정도 함께 남고, 이후로는 새로 생기거나 수정된 파일만 자동으로 따라잡습니다.

03한글 문서

맥이 못 여는 한글 문서, Lupa가 엽니다

macOS의 Spotlight·QuickLook은 HWP를 열지 못합니다. Lupa는 자체 렌더러를 내장해 한컴오피스 없이 본문을 검색하고, 표·서식이 살아있는 페이지로 미리 봅니다.

✓HWP·HWPX 본문을 통째로 인덱싱 — "위약금" 한 단어로 계약서 찾기
✓한글에서 연 것 같은 실제 레이아웃 미리보기 (한컴 설치 불필요)
✓스캔 PDF 한국어 OCR — 이미지 속 글자까지 검색
✓조사 자동 처리 · 단어 중간 조각 검색 ("보호정책"으로 "정보보호정책" 문서 찾기)

WIN윈도우용

윈도우에서도, AI 에이전트가 내 파일을 찾습니다

폴더를 등록하면 파일 이름과 문서 내용을 자체 색인으로 찾습니다. 그 색인을 MCP 서버와 CLI로 열어주기 때문에, Claude Code 같은 에이전트가 디스크를 직접 뒤지는 대신 Lupa에게 물어보게 됩니다. 전부 이 PC 안에서만.

✓한국어 2-gram 색인 — “보호정책”으로 “정보보호정책” 문서가 찾힙니다. 조사가 붙은 “동방을”도 “동방”으로 매칭됩니다
✓문서 내용 검색 — PDF · Word · Excel · PowerPoint · 텍스트
✓Claude Desktop · Claude Code 원클릭 연결 — 앱의 ‘AI 에이전트 연결’ 패널에서 연결을 누르면 claude_desktop_config.json에 Lupa가 자동 등록됩니다. 기존 설정은 보존 사본을 만들고, 어긋나면 되돌립니다. 에이전트를 재시작하면 search_files·get_content 두 도구가 붙습니다
✓검색 문법 동일 — c:계약 -임시 종류:PDF 크기:>10mb 날짜:이번주
✓네트워크 코드가 없습니다 · .NET 설치 필요 없음
맥용과 다른 점을 먼저 밝힙니다. 윈도우용은 첫 공개 버전(v0.1.0)이라 위 한글 문서 섹션의 기능이 아직 들어 있지 않습니다 — HWP 본문 검색과 스캔 PDF OCR은 미구현이고 (이름으로는 찾힙니다), 파일명만 보는 속도는 Everything 쪽이 더 빠릅니다. 윈도우용의 쓸모는 내용 검색과 에이전트 연결에 있습니다.

아직 코드 서명이 없습니다. 처음 실행하면 SmartScreen이 “Windows가 PC를 보호했습니다”를 띄우니 추가 정보 → 실행을 눌러 주십시오. 함께 올린 .sha256으로 받은 파일이 온전한지 확인할 수 있습니다.

05프라이버시

프라이버시가 기본값

Lupa에는 네트워크 권한이 없습니다 — 말이 아니라 직접 확인할 수 있습니다. 터미널에서 codesign -d --entitlements - /Applications/Lupa.app을 실행하면 샌드박스·앱 그룹·사용자가 고른 폴더 접근, 이 네 가지 권한만 나오고 네트워크 권한(network.client)은 없습니다.

100% 온디바이스

인덱싱·검색·OCR·HWP 렌더링 전부 이 Mac 안에서만 처리됩니다.

데이터 수집 없음

어떤 정보도 밖으로 전송하지 않습니다. App Store 개인정보 라벨: "데이터가 수집되지 않음".

선택한 폴더만

macOS 샌드박스 안에서, 사용자가 직접 등록한 폴더에만 접근합니다.
